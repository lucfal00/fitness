# Fitness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Il comportamento di ogni schermata è nella spec (sezioni citate); qui firme, casi di test con valori attesi e criteri di accettazione. Il codice non è duplicato nel piano.

**Goal:** PWA offline per pianificare e registrare allenamenti con grafici di progresso, installabile su iPhone e PC.
**Architecture:** HTML/CSS/JS ES modules senza build, base copiata da Habits. Calcoli puri in `js/logic.js` e `js/metrics.js`, merge in `js/merge.js`, persistenza solo in `js/store.js`, una vista per file in `js/views/`.
**Tech Stack:** HTML, CSS, JS (ES2022), Service Worker, WebCrypto, CompressionStream, `node --test` (Node 24).
**Spec:** `docs/superpowers/specs/2026-10-28-fitness-design.md`
**Habits (sorgente dei moduli copiati):** `HABITS = C:/Users/falco/Documents/App/habits`
(se è ancora vuota perché la sessione Habits non si è spostata: la cartella di lavoro della sessione "Habits", oppure `git clone https://github.com/lucfal00/habits`).

## Global Constraints

- Nessuna dipendenza esterna, nessun build step.
- Date locali `YYYY-MM-DD`, mai UTC; settimana lun–dom; `weekday` 1 = lunedì.
- UI in italiano; input testo `font-size ≥ 16px` (niente zoom iOS); target tocco ≥ 44 px.
- Tutto il testo utente/import passa da `esc()`; colori da `safeColor()`.
- `localStorage` chiavi `fitness.v1`, `fitness.v1.corrupt`, `fitness.sync`; cache SW con prefisso `fitness-`.
- `logic.js`, `metrics.js`, `merge.js`, `library.js` senza DOM, storage, rete.
- Accento: `--accent #c62f3a`, `--accent-strong #b3202d` (testo bianco, contrasto 6,6:1), scuro `#f07c7c` con `--on-accent #0f1117`.
- Server locale porta **8081** (Habits usa 8080).
